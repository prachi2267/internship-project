# 🐞 BugFlow — Jira-Style Project & Issue Tracker

A full-stack project and bug tracking web application built with **Java**, **Spring Boot**, **Spring Security**, **Spring Data JPA**, **MySQL**, and a **Kanban-style frontend**.

## 🚀 Live Demo
🔗 **[Open BugFlow Live App](https://internship-project-production-729f411f.up.railway.app/)**

## ✨ Key Features
- **Authentication & Roles:** Sign Up and Login support with user roles (`DEVELOPER`, `PROJECT_MANAGER`, `ADMIN`).
- **Project Management:** Create and switch between projects (`+ New Project`) with unique project keys.
- **Kanban Board:** Track issues across **To Do**, **In Progress**, **In Review**, and **Done** columns with live status updates.
- **Issue CRUD & Filtering:** Create, edit, and delete issues, plus filter by keyword search and priority (`LOW`, `MEDIUM`, `HIGH`, `CRITICAL`).
- **Issue Comments:** View and post comments directly on individual issues.

## 🛠️ Tech Stack
- **Backend:** Java, Spring Boot, Spring Security, Spring Data JPA, Maven
- **Database:** MySQL
- **Frontend:** HTML5, Tailwind CSS, JavaScript
- **Deployment:** [Railway](https://railway.com) & [GitHub](https://github.com)
